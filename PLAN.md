# План работ для PillsReminderTgBot

## 1. Уточнение требований (зафиксировано)
- Расписание: ежедневно в 07:00, таймзона `Russian Standard Time`.
- Таблетки одного типа.
- Повторные уведомления: в течение 3 часов, каждые 30 минут.
- Параметры повторов должны быть в `appsettings.json` и переопределяемы через переменные окружения.
- Без «тихих часов».
- Только личные чаты.

## 2. Настройка Telegram-бота
- Создать бота через @BotFather и получить токен.
- Настроить имя/описание/аватар бота (опционально).
- Добавить список команд через BotFather:
  - /start — включить напоминания
  - /stop — отключить напоминания
  - /status — текущий статус
  - /help — помощь
  - /test — тестовое напоминание
- Сохранить токен в секретах/переменных окружения проекта.

## 3. Архитектура и хранение данных
- Модели данных: Пользователь, Напоминание, Событие, Статус подтверждения.
- Хранение без БД: все данные в памяти процесса.
- Таймзона фиксированная: `Russian Standard Time`.

## 4. Логика напоминаний
- Генерация «события» по расписанию.
- Отправка сообщения с кнопкой «Я выпил».
- Ожидание подтверждения в течение X минут.
- Если нет подтверждения — повторное уведомление с тем же событием.
- Завершение повторов после подтверждения.

## 5. План реализации в коде
- Подключить Telegram Bot API библиотеку.
- Реализовать обработчики команд:
  - /start, /help
  - /schedule (создание/редактирование)
  - /settings (таймзона, интервал повторов)
- Реализовать callback-кнопку «Я выпил».
- Реализовать планировщик (background service) для отправки напоминаний.
- Реализовать логику повторных отправок.

## 6. Конфигурация и запуск
- Настроить конфиги (appsettings + env vars).
- Локальный запуск и тестирование на Windows.
- Docker/compose для деплоя на Linux.

## 7. Тестирование
- Юнит-тесты логики расписаний и повторов.
- Интеграционные тесты отправки сообщений (по возможности).
